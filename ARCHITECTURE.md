## Module responsibilities

### `src/core/` — pure data model, no Qt GUI

- **`VoxelFrame`** — sparse map `(x,y,z) → RGB`. The on-disk JSON is a direct reflection (DEC-003).
- **`AnimationTimeline`** — ordered vector of `VoxelFrame`, plus `fps`, playback mode, current frame index.
- **`ShapeMask`** — boolean grid `[gridSize]³` defining addressable LED positions. Generated by one of four algorithms (Cube/Sphere/Cylinder/Pyramid, `docs/SPEC.md` §3.3). Regenerated on shape or size change; never stored per-frame (CLAUDE.md "Key design decisions" #4).
- **`JsonSerializer`** — round-trips `AnimationTimeline` + `ShapeMask` metadata to the v1.0 wire format.

This layer is the wire protocol with the Python scripting subprocess. Any change to data shapes here is also a change to the public file format and the script API.

### `src/renderer/` — OpenGL viewport

- **`CubeViewport`** (`QOpenGLWidget`, `QOpenGLFunctions_4_3_Core`) — owns the GL context. One instanced draw call per LED mesh type (on / ghost). Hides LEDs by setting instance scale to zero, never by removing them from the buffer (DEC-001).
- **`OrbitCamera`** — spherical coords (theta, phi, radius, target); produces view and projection matrices for the renderer. Manual implementation, no OrbitControls-equivalent dependency (DEC-007).
- **`LedInstanceBuffer`** — two VBOs (on-LEDs, ghost-LEDs), stride 32 bytes per instance (`LedInstance` struct: position, RGB, scale).
- **`shaders/`** — GLSL 4.3 Core; compiled from Qt resources (`:/shaders/*`). `led.vert` constants are binding (LED radius = 0.38, ghost radius = 0.17, ghost opacity = 0.22 — DEC-002, AV-003).

### `src/audio/` — real-time audio pipeline

PortAudio + KissFFT. The defining constraint is that the PortAudio callback is real-time-safe: no Qt calls, no allocations, no mutexes (DEC-011, AV-008). Communication with the Qt thread is via a single-producer-single-consumer ring buffer.

- **`AudioWorker`** — opens the PortAudio stream, owns the callback, drains the ring buffer on the audio thread.
- **`FFTProcessor`** — Hann-windowed FFT, log-spaced band mapping (bass / mid / treble), onset detection.
- **`AudioReactiveEngine`** — dispatches to the four modes (EqBars, BeatPulse, WaveformSlice, SpectralColour); applies blend; optionally captures resulting frames into the timeline.
- **`AudioDevicePicker`** — Qt widget listing PortAudio devices, including monitor sources where available.

### `src/scripting/` — preset runtime bridge

- **`PresetRunner`** — owns a `QProcess` running `python3` with the active preset. Communication is JSON over stdin/stdout: each frame the app sends an audio-feature packet, the preset emits a `VoxelFrame` JSON, the renderer consumes it.
- **`PresetEditorPanel`** — in-app Qt editor for `.py` files, with a Python syntax highlighter, preset browser, and error console fed by stderr from `PresetRunner`.
- **`QFileSystemWatcher`** watches `presets/builtin/` and `presets/user/` for hot-reload.

### `src/ui/` — Qt widgets

Thin presentation layer; widgets emit signals into `MainWindow`, which mediates between UI and core data.

- **`ColorPickerWidget`** — RGB sliders, hex input, 18-preset palette, 16-slot recent history.
- **`SliceControlWidget`** — three independent sliders for X/Y/Z slice; emits `sliceChanged`.
- **`TimelineWidget`** — scrollable strip of frame thumbnails; play/stop/duplicate/delete.

### `presets/` — Python preset runtime

- **`presets/led_cube/`** — runtime package imported by every preset (`from led_cube import Preset`). Contains the `CubeProxy` helper that wraps the LED array and the `Preset` base class.
- **`presets/builtin/`** — shipped presets (target: 20; currently 2).
- **`presets/user/`** — user-authored presets; scanned at startup and on filesystem change.

## Key invariants

These are non-negotiable. They are also enumerated in `ATTACK_VECTORS.md` with detection methods.

1. **One instanced draw call per LED mesh type** (DEC-001 / AV-001).
2. **LED radius is 0.38 exactly; ghost LED radius is 0.17, ghost opacity 0.22** (DEC-002 / AV-003).
3. **Voxels are stored sparse — absent means off, never null** (DEC-003 / AV-004).
4. **Slice filter is view-only — never destructive** (DEC-004 / AV-005).
5. **Grid size capped at 32** (DEC-005 / AV-006).
6. **Shape change requires confirmation when frames have content** (DEC-006 / AV-007).
7. **PortAudio callback: no Qt calls, no allocations, no mutexes** (DEC-011 / AV-008).
8. **OpenGL 4.3 Core profile required — no fallback to lower versions** (AV-009).

## Cross-cutting concerns

### Threading model

Three threads of consequence:

| Thread | Owner | Responsibilities | Forbidden |
|---|---|---|---|
| Main / Qt | Qt event loop | UI, viewport rendering, JSON I/O, timeline editing | Blocking on audio or script processes |
| Audio | PortAudio | Capture callback, FFT, feature extraction, write to SPSC ring | Qt calls, allocations, mutexes (AV-008) |
| Script | `QProcess` | Run a Python preset to produce frames | Direct access to GL or Qt widgets |

Audio → Main and Script → Main both communicate via lock-free queues / `QProcess` stdio. Audio features are read by Main once per frame to feed the renderer or the preset.

### Error handling

- File I/O errors (load / save JSON, vendor missing) surface as `QMessageBox` dialogs at the action site.
- Preset runtime errors are written to the in-app error log (never raised as dialogs — they fire too often during edit / save cycles).
- GL initialisation failure (< 4.3) shows an early dialog and exits cleanly — no fallback.

### Resource paths

- Shaders are embedded via Qt's resource system (`:/shaders/led.vert`, `:/shaders/led.frag`). No external files at runtime for shaders.
- Built-in presets are copied next to the binary at install (CMake `install(DIRECTORY presets/ …)`).
- User presets live in a platform-appropriate user-data dir, not in the install tree.

### Coordinate conventions

- Voxel coordinates are integers in `[0, gridSize)³`.
- World coordinates are floats — the LED at voxel `(x, y, z)` sits at world position `(x - c, y - c, z - c)` where `c = (gridSize - 1) / 2`, so the grid is centred at the world origin.
- JSON keys are `"x,y,z"` strings (DEC-003); parsers must split on `,`.
